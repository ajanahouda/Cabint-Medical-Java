\#  Cabinet Médical - Java Management System



Ce projet est une application desktop développée en Java permettant la gestion des patients et la prise de rendez-vous pour un cabinet médical.



\## Fonctionnalités

\- Gestion des Patients : Ajout et affichage des informations personnelles (Nom, Prénom, CIN, etc.).

\- Prise de Rendez-vous : Planification des rendez-vous liée à un patient spécifique avec gestion de l'heure.

\- Base de données : Persistance des données via MySQL et JDBC.

\- Interface Graphique : Interface intuitive développée avec Java Swing.



\## Technologies utilisées

\- Java SE (Swing API)

\- MySQL (Base de données relationnelle)

\- JDBC (Driver Connector)

\- Pattern DAO (Data Access Object)



\## Installation

1\. Importer le fichier SQL fourni dans votre base de données MySQL.

2\. Configurer la connexion dans 'ConnexionBD.java'.

3\. Exécuter 'FormeGUI.java'.
